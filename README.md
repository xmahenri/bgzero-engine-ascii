# 📹 BGZero Engine - ASCII

Real-time ASCII video renderer built with JavaScript and HTML5 Canvas.

🔗 **Live Demo:** https://xmahenri.github.io/bgzero-engine-ascii/

## Features

- Real-time ASCII rendering
- Webcam support
- Video upload support
- Audio controls
- Timeline controls
- Custom density system
- Brightness adjustment
- HUD toggle
- Minimal cyberpunk UI

## 💻 Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API

## Future Plans

- Rendering presets
- Matrix mode
- CRT filter
- Neon mode
- WebGL renderer
- GPU acceleration

# 📹 BGZero Engine - ASCII

Real-time ASCII video renderer built with JavaScript and HTML5 Canvas.

🔗 **Live Demo:** https://xmahenri.github.io/bgzero-engine-ascii/

## ⚙️ Features

- Real-time ASCII rendering
- Multiple ASCII visualization modes
    - Binary Mode
    - Special Mode
    - Full Characters Mode
- Dynamic color presets
    - Original
    - Green
    - Blue Tech
    - Red
    - Pink
- Webcam support
- Video upload support
- Responsive video scaling
- Volume controls
- Timeline controls
- Density adjustment
- Font size customization
- Brightness adjustment
- HUD toggle system
- Minimal cyberpunk UI
- Vertical and horizontal video support

## 💻 Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
